# Butterfly — publicación en Vercel
1. Descomprimir el ZIP. Abrir index.html para revisar el sitio localmente.
2. Crear un repositorio en GitHub y subir el contenido de esta carpeta (index.html debe quedar en la raíz). También se puede usar GitHub Desktop para subir los archivos.
3. Entrar a https://vercel.com/new, importar el repositorio y seleccionar Framework Preset: Other. No configurar comando de compilación ni instalación. Mantener la raíz del repositorio como directorio del proyecto. Pulsar Deploy.
4. Para agregar enlaces públicos de Figma, turnaround, modelo 3D, renders, AR, VR y maqueta, editar el objeto links al inicio de script.js. Los espacios vacíos aparecen como pendientes, no como trabajos terminados. Los enlaces abren recursos externos; no son visores integrados.
5. Para modificar textos, editar index.html; para cambiar colores, style.css. Las láminas originales del PDF están en assets. La paleta web es aproximada. El video adjunto se incluye como registro del proceso, no como turnaround verificado.
6. Subir cambios a GitHub para que Vercel vuelva a publicar.
Nota: la consigna exige Blogspot; confirmar aceptación de Vercel o enlazar el sitio desde Blogger. No se ha realizado un despliegue remoto.
